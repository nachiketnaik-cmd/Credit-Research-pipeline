# Workflow

> The build order Claude followed. Each step ends with my review and explicit approval.

**Standing rules for every step**
- When drafting a new section, add it to the master report in its correct TOC (table of contents) position. Never edit previously approved work unless I explicitly ask.
- **Closed loop:** no internet. Use only the filings I supplied plus sources I verified first (rating agency reports, credit agreements).
- When referring to a step, name both the workflow step and its TOC (table of contents) section number.

## Steps

1. **Collect filings.** Download annual and quarterly reports from the official source. Check when the fiscal year ends; never assume.
2. **Find public rating reports** from the major agencies.
3. **Pick peers (human step).** Shortlist at least 3 listed competitors and confirm they really compete. I make the final choice.
4. **Extract data with Claude.** Web search off. One workbook with an annual sheet, a quarterly sheet and calculation sheets, plus a peer workbook. LTM for flow items = latest FY + current YTD − prior-year YTD; balance-sheet items use the latest figure.
5. **Check every number by hand,** especially revenue and other headline lines. Then build the ratios: leverage, debt/equity, debt/capital and so on.
6. **Appendix A:** summary financial statements.
7. **Business overview:** what the company does and how it makes money.
8. **Pick the industry's key ratios.** Each industry is judged differently (FCF for some, gross debt/EBITDA for others). Use the industry metrics file.
9. **Industry landscape and competitive positioning.**
10. **Key financial snapshot workbook,** with every ratio the industry metrics file requires. I place the table in the report myself.
11. **Financial and credit analysis workbook** in a fixed column format (3 fiscal years, LTM, latest quarters). I build the charts and hand them back.
12. **Capital structure and covenant analysis.** Full debt breakdown plus equity and total capitalization. For covenant detail, ask me for the actual credit agreement; I verify it before supplying it.
13. **Investment thesis and credit outlook,** using the industry metrics for credit positives and upgrade/downgrade triggers.
14. **Final credit scorecard** per the scoring methodology.
15. **AI fund manager review:** feed the full draft to a separate AI session for a professional critique. Final check.
