# AI Fund Manager Review (example)

> The last step of the workflow: a separate Claude session reads the full draft as a skeptical bond fund manager would, before it goes to the mentor. Summary of one review, with report content removed.

**Verdict:** "This is not sendable in its current state."

**58 issues:** 9 critical · 21 material · 28 presentation/consistency

## What it looked for

- **Critical:** labeling errors that touched every table, wrong inputs that flowed into several figures, the same metric stated several different ways, and conclusions the report's own numbers didn't support.
- **Material:** method choices a professional reader would question, comparisons on mismatched periods, and tables that contradicted each other.
- **Presentation:** chat and working-file language left in the draft, file names referenced in the text, broken cross-references, sentences that stopped mid-thought, empty sections, and mixed date and unit formats.

## What happened next

Each finding was checked against the source files before being accepted. Then:
- **One-off errors** were fixed.
- **Systematic errors** became standing rules in the learnings log, so the next report starts with them already fixed.

Large fixes went through a written change inventory: every old reference quoted next to its replacement and approved before any edit.
